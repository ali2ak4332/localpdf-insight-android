# Roadmap

## M0 — Project hardening (current)
- Git-ready package layout
- deterministic Windows launch path
- backend smoke tests
- extracted-folder detection and diagnostics

## M1 — Retrieval quality
- SQLite/FTS5 index
- local embeddings
- reciprocal-rank fusion: lexical + semantic
- robust visual reranking
- retrieval evaluation fixture set

## M2 — Product UX
- markdown answers
- clickable citations embedded in answers
- source thumbnails and selection state
- drag-and-drop import
- per-document indexing progress
- first-run model wizard

## M3 — Visual document intelligence
- table/chart region extraction
- page/region-level visual embeddings
- optional PixelRAG adapter where supported
- compare pages/documents workflow

## M4 — Release engineering
- PyInstaller signed executable
- Inno Setup installer
- automatic update channel
- crash logging kept local and user-controlled
